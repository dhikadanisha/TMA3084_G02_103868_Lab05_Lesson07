## How to run a Flutter project (VS Code)
```bash
flutter doctor
flutter create <project_name>        # or Ctrl+Shift+P > Flutter: New Project
# copy the lib/ (and test/) files and pubspec.yaml from this folder into the project
flutter pub get
flutter run                          # or F5
```
For Vibe Task 5 also run `flutter pub add provider`.
